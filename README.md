# Isometric City Map

一个基于 [Three.js](https://threejs.org/) 的等距视角 3D 城市地图项目，包含交互式地图浏览、缩放、旋转等控制功能。

## 功能特性

- 🏙️ 等距视角 3D 城市地图，含建筑、道路、绿化、水域等要素
- 🕹️ 支持缩放（`+` / `-`）、旋转、重置视角
- 🚗 城市中的动态车辆与角色
- 🖱️ 鼠标 / 触摸板交互控制

## 项目结构

```
city-map/
├── index.html          # 入口页面
├── src/                # 源代码
│   ├── game/           # 游戏逻辑（渲染、角色、车辆、控制等）
│   └── map/            # 地图生成（地形、道路、街区、装饰等）
├── assets/             # 图片、GLB 模型等静态资源
├── vendor/three/       # Three.js 本地依赖
└── tools/              # 辅助脚本
```

## 本地预览

项目是纯静态页面（无构建步骤），只需要一个静态文件服务器即可运行。

### 方式一：Python 静态服务器（推荐）

在项目根目录执行：

```bash
python3 -m http.server 8000
```

然后浏览器打开 <http://localhost:8000> 即可预览。

> 若 8000 端口被占用，可换一个端口：
>
> ```bash
> python3 -m http.server 8080
> ```

### 方式二：直接打开（不推荐）

直接双击 `index.html` 在浏览器打开也可以查看，但由于页面通过 `importmap` 加载 ES Module，部分浏览器可能因本地文件访问限制（CORS）无法正常加载 Three.js，因此推荐使用静态服务器方式预览。
